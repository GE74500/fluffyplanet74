# FLUFFY PLANET — site statique

Site vitrine original inspiré de l'ambiance générale des sites de loisirs premium : typographie display, grille éditoriale, néons, micro-interactions et animations au scroll.

## Fichiers
- `index.html` — structure et contenu
- `styles.css` — design responsive
- `script.js` — menu, compteurs, onglets, galerie, curseur et formulaire
- `assets/logo.png` — logo fourni

## Mise en ligne gratuite avec GitHub Pages
1. Créer un compte GitHub.
2. Créer un dépôt public nommé `TONPSEUDO.github.io`.
3. Déposer tous les fichiers et dossiers de ce projet à la racine.
4. Dans Settings > Pages, choisir la branche `main` et le dossier `/ (root)`.
5. L'adresse sera `https://TONPSEUDO.github.io`.

Le formulaire utilise `mailto:` : il n'y a donc pas de serveur ni de base de données à payer.
Les visuels de la galerie utilisent actuellement des images distantes Unsplash. Tu peux les remplacer par tes propres photos dans `styles.css`.
